## Neue Seitenvorlage – gemeinsame Regeln für E4-BAU-19…21
- Muster (lesen, nicht ändern): `src/vorlagen/seiten/einsatzgebiet.mjs` (Seitenobjekt, Abschnitte, Schlussband), `src/vorlagen/seiten/hub.mjs` (Listen, Verzeichnisse), `src/vorlagen/seiten/preise.mjs` (Arbeitsansicht), Inhaltsmodul `src/inhalte/einsatzgebiet.mjs`.
- Eine Vorlage ist ein Modul in `src/vorlagen/seiten/`, das `export function seiten(k)` exportiert und eine Liste von Seitenobjekten liefert:
  `{ pfad, titel (≤ 60), beschreibung (70–155), typ: 'arbeit'|'erzaehlung'|'system', ansicht: 'V09'|'V11'|'V12', sitemap, koerperKlasse, stile: ['<bündel>'], brotkrumen: [{ titel, pfad }], jsonld: [...], inhalt: (sk) => html`…` }` – `sitemap` und `ansicht` wie in `src/konfig/routen.mjs`.
- HTML nur mit `html``…`` aus `bau/lib/html.mjs` (escaped jeden Wert). Fließtext mit Mini-Syntax über `text()` aus `bau/lib/inhalt.mjs`. Kein `roh()` in Seitenvorlagen. Keine `style=`-Attribute, kein Inline-Skript (CSP).
- Texte stehen im Inhaltsmodul `src/inhalte/<name>.mjs`, nie in der Vorlage. Werte aus der Konfiguration (`sk.konfig.betrieb`, `sk.konfig.leistungen`, …) direkt ausgeben – Platzhalter erscheinen dann sichtbar markiert, das ist gewollt.
- Struktur: genau eine `<h1>`; jede `<section>` mit `aria-labelledby` auf ihre Überschrift; Überschriften ohne Sprung. Abschnittskopf über `abschnittKopf({ id, titel, einleitung })` aus `src/vorlagen/teile/abschnitt.mjs`. Brotkrumen-JSON-LD über `brotkrumenLd(k.basisUrl, stufen)`.
- Gemeinsame Klassen (global, ohne eigenes CSS nutzbar): `raster`, `sektion`, `sektion-dicht`, `band`, `band-dunkel`, `schluss`, `schluss-teilung`, `schluss-handlung`, `gruppe-kicker`, `gruppe-einleitung`, `gruppe-teilung`, `fliesstext`, `rand-titel`, `weiter` (+ `weiter-titel`, `weiter-text`, `weiter-pfeil`), `faq-teilung`, `knopf knopf-primaer|knopf-sekundaer`, `hinweis`, `preis-tabelle` (mobil als Blöcke). Icons über `sk.icon('<name>')` nur aus `src/konfig/icon-vertrag.mjs`.
- Eigenes CSS nur in deinem Ansichts-Bündel `src/assets/css/ansichten/<bündel>/<datei>.css` innerhalb `@layer komponenten { … }`; jeder Wert über Tokens aus `src/assets/css/token.css` (Token-Prüfer). Breakpoints nur `min-width: 30em|48em|64em|80em`. Die Seite lädt das Bündel über `stile: ['<bündel>']`; der Prüfer `budgets/stil-fehlt` meldet Klassen, deren Regeln die Seite nicht lädt.
- Benachbarte Abschnitte unterscheiden sich in mindestens zwei von drei Merkmalen: Fläche (normal/`band`/`band-dunkel`), Layout, Dichte.
- Links nur auf Routen aus `src/konfig/routen.mjs`. Nichts von den Wettbewerbern übernehmen; ihre Seiten im Repo NICHT öffnen.
- Sprache wie `_werkstatt/pakete/_gruppenseite.md` „Sprache“: Sie-Anrede, ruhig, konkret; keine Zahlen, Paragrafen, Prozente, Jahre ohne Fakt aus einem Faktenblatt; keine Superlative, Marken, Zertifikate; keine Zusagen außerhalb der Konfiguration.
- Prüfen: `node bau/bauen.mjs --messen --pruefen --aus=.cache/<KENNUNG>/dist` (alle Prüfer 0 Fehler; vorhandene Warnungen fremder Seiten nur melden) · `npm test` · Vorschau `node bau/vorschau.mjs --aus .cache/<KENNUNG>/dist --port <PORT> --still &` · `node _werkstatt/werkzeuge/bildsatz.mjs --basis http://127.0.0.1:<PORT> --pfade <pfade> --schemata light,dark --aus .cache/<KENNUNG>/bilder` · `node _werkstatt/werkzeuge/axe.mjs` und `ueberlauf.mjs` auf deine Pfade (Aufrufe im README der Werkzeuge) · Desktop 01–02 und Mobil 01–02 ansehen und nachschärfen · Vorschau per PID beenden.
